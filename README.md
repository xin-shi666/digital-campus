# 校园数字孪生交互系统

本项目是**浙江树人学院**信息科技学院《计算机图形学》课程期中作业。

## 项目简介

基于 HTML + JavaScript + Three.js 构建的校园数字孪生交互系统，在浏览器中呈现三维校园场景，支持用户自由浏览、点击建筑查看信息、多视角切换和图层控制等交互功能。

## 功能特性

### 核心功能

1. **三维场景浏览** — 使用鼠标旋转、缩放、平移，自由探索三维校园
2. **对象信息展示** — 点击建筑/设施弹出信息面板，查看详细介绍
3. **多视角切换** — 一键切换透视图、鸟瞰图、前视图、侧视图
4. **图层控制** — 独立开关建筑物、道路、植被、设施图层的显示
5. **光影系统** — 动态方向光 + 环境光，模拟真实光照和阴影

### 场景内容

- **建筑**：教学楼A/B栋、图书馆、行政中心、食堂、体育馆、宿舍楼
- **道路**：主干道 + 支路网，含道路标线
- **植被**：40+ 棵随机大小树木，沿道路和建筑分布
- **设施**：路灯、长椅、中心喷泉广场

## 技术栈

| 技术 | 用途 |
|------|------|
| Three.js 0.160 | 3D 渲染引擎 |
| OrbitControls | 轨道相机控制 |
| ES Modules | 模块化代码组织 |
| WebGL | 浏览器硬件加速渲染 |

## 快速开始

1. 克隆仓库
```bash
git clone <仓库地址>
cd campus-digital-twin
```

2. 启动本地服务器（任选一种）
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# VS Code
安装 Live Server 插件并启动
```

3. 浏览器访问 `http://localhost:8080`
